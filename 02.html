02 · power 🟢 SZINT 1 — alacsony kockázat

Ne engedd, hogy a Windows spóroljon a teljesítményedből

A Windows alapértelmezett energiakezelése folyamatosan visszafogja a CPU-t, hogy fogyasztást spóroljon — ez játék közben mikro-akadásokhoz vezethet. Ebben a fejezetben egy saját, teljesítményre optimalizált energiasémát építünk fel, lépésről lépésre.

Windows power mgmt Power Plan Processor Boost Core parking Idle policy Kompromisszumok
02.1

Windows power management

CÉL Megérteni, hogy a Windows alapból is "spórol" a teljesítményből — ezt kell feloldani, mielőtt bármi mélyebbe belemennénk.

→ Windows-ban alapértelmezetten a Kiegyensúlyozott (Balanced) terv fut, ami folyamatosan le-fel kapcsolgatja a CPU-t a fogyasztás miatt — ez játék közben mikro-akadásokat okozhat
→ Az Ultimate Performance vagy egy egyedi terv beállítása ajánlott — ez alapból el van rejtve, powercfg paranccsal kell előhozni
ℹ
Laptopnál ez plusz meleget és rövidebb akkumulátor-időt is jelent — ha viszont mindig töltőről használod a laptopot játék közben, ez egyáltalán nem okoz gondot.
02.2

Power Plan

CÉL Egy saját, minden értékében maximumra állított terv, ami nem enged vissza semmit spórolásból.

→ Alapnak az Ultimate Performance energia sémát ajánlom
BEÁLLÍTÁS MENETE
Nyomj Win + R-t, írd be, hogy cmd, majd Enter — megnyílik a parancssor.
Írd be a következő parancsot:
> powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61
Ennek hatására megjelenik egy új energiaséma a gépen, Ultimate Performance vagy Maximális teljesítmény néven.
Lépj be az Energiagazdálkodás beállításaiba, és jelöld be az új sémát — csak ekkor lesz aktív.
→ Érdemes ezután tovább szerkeszteni a sémát (Speciális beállítások módosítása):
Processor power management → Minimum processor state 100%
Processor power management → Maximum processor state 100%
Core Parking minimum 100%
System cooling policy Active
PCI Express → Link State Power Management Off
USB Selective Suspend Off
Sleep → Allow wake timers Never
Wireless Adapter Settings → Power Saving Mode Max Performance
Hard disk → Turn off hard disk after Never
💡
Ha a processzornak van integrált grafikus kártyája, azt is érdemes itt Maximum Performance-re állítani.
→ CPU minimum és maximum állapot: mindkettő 100%-ra (ne engedje le magát alacsonyabb állapotba)
02.3

Processor power management

CÉL A CPU saját belső energiakezelési logikáját (EPP / Speed Shift) is a teljesítmény felé tolni.

→ EPP (Energy Performance Preference) / Speed Shift érték: 0 (maximális teljesítmény irányba)
→ Ez a Power Plan haladó beállításai közt érhető el, néhol csak regisztri-szerkesztéssel jelenik meg
02.4

Boost

CÉL Biztosítani, hogy a CPU ténylegesen fel tudjon menni a hirdetett boost órajelére, ne csak papíron.

→ Turbo Boost / PBO legyen engedélyezve a Power Planben
→ Ha az órajel a 01. fejezetben mért adatok szerint nem éri el az elvárt boost-ot terhelés alatt, a hiba oka itt, vagy a hőmérséklet/power limit fejezetben (03 – CPU) keresendő
02.5

Core parking

CÉL Elkerülni, hogy a Windows "pihentessen" magokat, amikor épp szükség lenne rájuk.

→ Core Parking teljesen kikapcsolva (minimum = maximum = 100%) — így egy mag sem kerül parkoltatásra terhelés közben
→ Ez különösen fontos alacsonyabb magszámú CPU-knál (pl. 4 magos, HT nélküli processzoroknál), ahol egy leparkolt mag érezhető teljesítménycsökkenést okozhat
02.6

Idle policy

CÉL A rendszer ne lépjen be energiatakarékos állapotokba (C-states) akkor, amikor a válaszidő számít.

→ Idle/Sleep timerek Never-re állítva
→ A mély C-state-ek (C3+) viselkedését van, aki haladó szinten is korlátozza — ez inkább a 03 – CPU fejezetbe, ThrottleStop/BIOS szintre tartozik, itt csak jelöljük
02.7

Energiagazdálkodási kompromisszumok

→ Asztali gépeknél ezzel csak nyerni lehet — folyamatos az áramellátás, nincs kockázat
→ Laptopnál számításba kell venni, hogy szoktuk-e csak akkumulátorról használni, mert így gyorsabban merülhet. Ha mindig töltőről játszol, kockázatmentes, mert folyamatos az áramellátás
💡
Kompromisszum laptophoz: mivel laptopnál jelentősen rövidebb lehet az akkumulátor-üzemidő, érdemes két külön energiasémát fenntartani — akkumulátoros használatnál a gyári séma, játéknál pedig átváltás az Ultimate Performance-re.
⚠
Ez a fejezet tudatosan a teljesítmény felé billen. Ha valaki elsősorban mobilitásra/akkumulátorra optimalizál, ne ezt a tervet használja alapértelmezettként.
